Codex是OpenAI推出的AI编程智能体，能够读取本地项目文件、理解自然语言需求并自动修改代码，相当于给开发环境配了一个能上手干活的AI搭档。它提供三种使用形态：桌面版、命令行版以及VS Code插件，三种形态共用同一份配置文件，配置一次即可在所有客户端生效，本文主要讲解桌面版。

安装

双击下载下来的chatgpt Installer.exe，注意chatgpt Installer.exe只是一个安装引导器，双击后会跳转到Microsoft store安装，chatgpt Installer.exe一定要放在一个英文路径下。

安装完成后如果发现无法启动，右键选中-应用设置-安装的应用-移动到C盘，重新启动即可，如果没有科学上网通常会白屏一段时间，正常启动过一次即可移动回D盘，安装完成一定要登录一次以确保 ~/.codex 配置目录已自动生成。

配置DeepSeek模型

获取 DeepSeek API Key

访问DeepSeek开放平台https://platform.deepseek.com/api_keys，登录后先进行充值，再进入API keys页面，点击”创建 API key”，密钥以 sk- 开头，创建后复制保存。

配置脚本

配置期间一定要杀死所有Codex的进程。

DeepSeek官方提供了一键配置脚本，自动完成备份、模型元数据写入和配置文件修改，无需手动编辑任何文件。

首次运行会要求输入DeepSeek API Key，菜单选项说明：第1项使用deepseek-flash模型；第2项使用deepseek-v4-pro模型；第9项恢复默认配置。

问题排查

如果遇到power shell输入命令后乱码或保存更改时报错，请更新power shell的版本

  • 方法一：通过WinGet安装更新
  • 方法二：通过Microsoft Store更新
    在Microsoft Store中搜索”PowerShell”，然后点击”获取更新”即可。

如果脚本提示找不到~/.codex目录：说明Codex尚未首次运行。先启动一次Codex，生成配置目录后再重新运行脚本。

需要恢复默认配置：再次运行一键脚本，选择菜单第 9 项即可还原到安装前的原始配置。
